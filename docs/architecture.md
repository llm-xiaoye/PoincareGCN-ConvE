# 模型架构

## 表示与编码

模型使用曲率为 -c、c > 0 的庞加莱球。实体和正向、逆向关系表使用绑定到 PoincareBall 的 geoopt.ManifoldParameter，由黎曼 Adam 更新。投影操作保持点位于半径 1 / sqrt(c) 内部。

几何模块提供指数映射、对数映射、莫比乌斯加法与矩阵乘法、庞加莱距离及成对距离。非线性层先映射到原点切空间，完成相应操作后映回球内。

训练三元组加入逆向边。图卷积在切空间中逐元素组合源实体与关系表示，变换消息并按目标节点取均值，再结合可学习的自环变换，最后映回庞加莱球。

## 解码与训练

头实体与关系各为 D 维，拼接后形成 2D 维表示；配置中的 reshape_height × reshape_width 必须等于 2D。

卷积层将表示映射到切空间并重排为单通道网格，执行二维卷积、展平并映回球内。双曲丢弃、归一化、莫比乌斯 ReLU 与线性层生成 D 维查询表示。

候选分数为查询到实体的负庞加莱距离，加上可学习的实体偏置。训练将同一查询的正确尾实体组成多目标标签，使用可选标签平滑的二元交叉熵；逆关系覆盖头实体预测。

## 评估与保存

过滤排序在计算平均排名、MRR 与 Hits@K 前屏蔽其他已知正确答案。头实体与尾实体均参与评估，最佳检查点只按验证集 MRR 选择。
